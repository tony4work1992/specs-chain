# Permission Definitions

| Role | Meaning |
| --- | --- |
| SYSTEM_ADMIN | Manage users and platform-level operational setup. |
| SALES_OPERATOR | Create and monitor orders. |
| FINANCE_OPERATOR | Confirm order payments. |
| PROJECT_ADMIN | Create and update project master data. |
| PROJECT_MANAGER | Manage project delivery context. |
| WORKFLOW_MANAGER | Create, update, and deactivate workflows. |
