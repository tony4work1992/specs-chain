# Fix Failing Tests

    ## Purpose

    Resolve failing tests without inventing undocumented behavior.

    ## Steps

    1. Read the failing test and referenced A3/FRD.
2. Identify whether the test or the docs are wrong.
3. Update the right artifact in dependency order.
4. Regenerate or refine implementation only after documentation is coherent.

    ## Expected Outputs

    - Aligned documentation and corrected tests
