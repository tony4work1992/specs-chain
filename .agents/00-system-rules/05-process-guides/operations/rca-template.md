# RCA Template

## Problem Statement

- What failed?
- Where was the impact observed?

## Evidence

- logs
- metrics
- traces
- deployment or config history

## Causal Chain

1. Immediate trigger
2. Technical cause
3. Process or control gap

## Preventive Actions

- technical prevention
- monitoring improvement
- process improvement

## Verification

- How will we know the fix actually reduced recurrence risk?
