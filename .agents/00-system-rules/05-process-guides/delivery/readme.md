# Delivery Process Guide

This folder contains process documentation for work that happens while delivering software but is not part of the software domain model itself.

Use this folder for:

- bug and defect handling
- release planning
- deployment execution
- rollback decisions
- hotfix handling
- change management

Keep these docs separate from BRD, FRD, A3, and A4 unless the software product itself models delivery workflow as a business capability.
