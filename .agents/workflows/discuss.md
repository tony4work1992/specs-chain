# Safe Discussion Mode (`/discuss`)

When the user calls this command, you are explicitly ordered to enter **Read-Only Discussion Mode**.

**CRITICAL DIRECTIVES:**
1. **DO NOT MODIFY ANYTHING:** You are strictly forbidden from using any file modification tools (`write_to_file`, `multi_replace_file_content`, etc.).
2. **DO NOT RUN SCRIPTS:** You are strictly forbidden from executing state-modifying bash commands.
3. **READ ONLY:** You may only use `view_file` and `grep_search` to gather context.
4. **THINK AND TALK:** Your only output should be analysis, discussion, brainstorming, and proposing plans. Wait for the user to either approve verbally or explicitly invoke `/do` before taking any irreversible action.
