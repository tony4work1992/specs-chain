# Generate Project Skeleton

    ## Purpose

    Create the documentation and implementation skeleton for a new project using the AI-first workflow.

    ## Steps

    1. Confirm module list and architecture decisions.
2. Create BRD and FRD placeholders or artifacts.
3. Generate A4 and A3 artifacts for the first critical flows.
4. Create baseline tests and prompts.
5. Review naming and glossary alignment.

    ## Expected Outputs

    - Initial docs tree
- First-pass domain and API specs
- Baseline tests and prompts
