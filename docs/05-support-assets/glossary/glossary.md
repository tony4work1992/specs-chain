# Glossary

| Term | Definition |
| --- | --- |
| BRD | Business requirement document describing why a capability exists. |
| FRD | Functional requirement document describing what the system must do. |
| A4 | Domain model specification describing aggregates, entities, value objects, and rules. |
| A3 | API specification describing transport behavior. |
| Facade | Curated cross-module contract that hides provider internals. |
| Port | Abstract contract for an external or cross-module dependency. |
