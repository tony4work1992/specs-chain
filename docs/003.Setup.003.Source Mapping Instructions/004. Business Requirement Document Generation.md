  - ** GENERATION RULES **
    - VALIDATE the REQUEST CODE (Folder Name) in "004.Develop.001.Delivery".
      - If the request code is FOUND, then keep proceed the below steps.
      - If the request code is NOT FOUND, then DO NOT proceed the below steps. STOP and INFORM user that "REQUEST NOT FOUND"
    - Read the "INPUT SOURCE FILES" to understand:
      - The conventions of the code prefix, how to do versioning for generated artifact
      - The generated artifact template to know the template of the generated artifact
      - The prompt to know exactly who you are and what you are assigned to perform
    - Check REQUEST CODE in `005.Develop.002.Artifacts`
      - If the REQUEST CODE is not existed. Create a new folder under `005.Develop.002.Artifacts/${REQUEST CODE}`
        - Generate a new file `./001.Requirement Development Workflow/Business Requirement Document.md` with provided INPUT SOURCE FILES
      - If the REQUEST CODE is existed. Under `005.Develop.002.Artifacts/${REQUEST CODE}`
        - COPY `./001.Requirement Development Workflow/Business Requirement Document.md` to `001.Requirement Development Workflow/000.Snapshots` AND RENAME it to `Business Requirement Document ${YYYY.MM.DD HH.MM.SS}.md`
        - UPDATE `./001.Requirement Development Workflow/Business Requirement Document.md` with provided INPUT SOURCE FILES
  - ** KNOWLEDGE REFERENCE **
    - Before generating, read `006.Knowledge/_index/manifest.json` to understand existing knowledge landscape.
    - Read `006.Knowledge/_index/by-feature.json` to cross-reference existing `what-we-build` knowledge.
  - ** KNOWLEDGE SYNC RULES **
    - After generating/updating the artifact, SPLIT and SYNC to `006.Knowledge/003. Business Requirement Document/`:
      - `${REQUEST CODE}.brd-scope-and-objectives.md` — Purpose, Scope, Stakeholders, Business Objectives
      - `${REQUEST CODE}.brd-functional-overview.md` — Dashboard Navigation, Core KPIs
      - `${REQUEST CODE}.brd-business-rules.md` — All BR-xx rules
      - `${REQUEST CODE}.brd-constraints-assumptions.md` — NFRs, Assumptions, Constraints
      - Each file MUST include metadata header with `Feature-Code`, `Source-File`, `Source-Version`, `Sections`.
    - Update all `006.Knowledge/_index/` files accordingly.
