# End User Requirement Generation
  - ** INPUT SOURCE FILES **
    - ** CONVENTIONS **
      - `003.Setup.003.Source Mapping Instructions/001.00 Common/001.00.01 Artifact Code Prefix Convention.md`
      - `003.Setup.003.Source Mapping Instructions/001.00 Common/001.00.02 Artifact Versioning Convention.md`
    - ** GENERATED ARTIFACT TEMPLATES **
      - `001.Setup.001.Artifact Templates/01. Requirement Development Workflow/01. End User Requirement.template.md`
    - ** PROMPT **
      - `002.Setup.002.LLM Prompt Templates/001. End User Requirement Generation.md`
  - ** GENERATION RULES **
    - VALIDATE the REQUEST CODE (Folder Name) in "004.Develop.001.Delivery".
      - If the request code is FOUND, then keep proceed the below steps.
      - If the request code is NOT FOUND, then DO NOT proceed the below steps. STOP and INFORM user that "REQUEST NOT FOUND"
    - Read the "INPUT SOURCE FILES" to understand:
      - The conventions of the code prefix, how to do versioning for generated artifact
      - The generated artifact template to know the template of the generated artifact
      - The prompt to know exactly who you are and what you are assigned to perform
    - Check REQUEST CODE in `005.Develop.002.Artifacts`
      - If the REQUEST CODE is not existed. Create a new folder under `005.Develop.002.Artifacts/${REQUEST CODE}`
        - Generate a new file `./001.Requirement Development Workflow/End User Requirement.md` with provided INPUT SOURCE FILES
      - If the REQUEST CODE is existed. Under `005.Develop.002.Artifacts/${REQUEST CODE}`
        - COPY `./001.Requirement Development Workflow/End User Requirement.md` to `001.Requirement Development Workflow/000.Snapshots` AND RENAME it to `End User Requirement ${YYYY.MM.DD HH.MM.SS}.md`
        - UPDATE `./001.Requirement Development Workflow/End User Requirement.md` with provided INPUT SOURCE FILES
  - ** KNOWLEDGE REFERENCE **
    - Before generating, read `006.Knowledge/_index/manifest.json` to understand existing knowledge landscape.
    - If this REQUEST CODE already has knowledge files, read `006.Knowledge/_index/by-feature.json` to identify existing knowledge files under `what-we-build` category for cross-referencing.
  - ** KNOWLEDGE SYNC RULES **
    - After generating/updating the artifact, SYNC the output to `006.Knowledge/001. End User Requirement/`:
      - Generate/Update `006.Knowledge/001. End User Requirement/${REQUEST CODE}.end-user-requirement.md`
      - Each knowledge file MUST include a metadata header with `Feature-Code`, `Source-File`, and `Source-Version`.
    - Update `006.Knowledge/_index/by-feature.json` and `006.Knowledge/_index/manifest.json` if new feature is added.
    - Update `006.Knowledge/_index/by-keyword.json` if new keywords are introduced.
