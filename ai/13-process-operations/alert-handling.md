# Alert Handling

## First Response

1. Acknowledge the alert.
2. Confirm whether the alert is real, duplicate, or noise.
3. Check current release, deployment, and incident context.
4. Decide whether to escalate into an incident.

## Classification

- false positive
- transient issue
- active degradation
- confirmed incident

## Required Output

- current status
- owner
- next check time or next action
- link to incident if escalated
