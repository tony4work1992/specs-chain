# Deployment Checklist

- [ ] Release scope is frozen and identified.
- [ ] Target environment and deployment window are confirmed.
- [ ] Database migrations are reviewed.
- [ ] Required configuration and secrets are ready.
- [ ] Rollback path is documented and tested where feasible.
- [ ] Smoke test list is prepared.
- [ ] Monitoring dashboards and alerts are open during deployment.
- [ ] Stakeholders know who is driving and who is watching.
- [ ] Post-deploy validation is completed.
