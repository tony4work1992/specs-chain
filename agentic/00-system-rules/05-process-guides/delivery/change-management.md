# Change Management

## Purpose

Track and communicate changes that may affect delivery risk, environment behavior, or operational support.

## Change Types

- code change
- configuration change
- migration change
- infrastructure change
- emergency change

## Required Metadata

- owner
- scope
- target environments
- risk level
- validation plan
- rollback plan
- communication plan

## Review Rule

Higher-risk changes require stronger review and a clearer rollback story before deployment.
