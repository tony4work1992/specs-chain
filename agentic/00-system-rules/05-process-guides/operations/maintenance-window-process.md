# Maintenance Window Process

## Purpose

Define a predictable way to perform planned maintenance with controlled user impact.

## Steps

1. Define scope, expected impact, and target window.
2. Notify stakeholders and affected users ahead of time.
3. Prepare validation and rollback steps.
4. Execute maintenance and monitor health.
5. Confirm service recovery and close communications.

## Required Inputs

- maintenance owner
- impacted services
- downtime expectation
- rollback plan
