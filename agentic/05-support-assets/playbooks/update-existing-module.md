# Update Existing Module

    ## Purpose

    Refine an existing module without breaking downstream consistency.

    ## Steps

    1. Read the current BRD, FRD, A4, A3, and TEST artifacts.
2. Update the highest necessary upstream artifact first.
3. Propagate changes downward in order.
4. Run the review checklist.

    ## Expected Outputs

    - Refined docs with preserved consistency
